# اعتماد و آسایش ایرانیان
## Corporate Holding Website — 2026

**هدف:** تبدیل وب‌سایت خدمات پرستاری فعلی به پرتال رسمی و مستقل شرکت مادر «اعتماد و آسایش ایرانیان» با پنج برند: سلامت اول، زندگی برتر، سفیر آرامش، مایکا و آکادمی سلامت.

**مرجع بصری:** پروتوتایپ تصویری V6؛ کیفیت تصویر، سلسله‌مراتب شرکت مادر، چارت تعاملی و سرعت بارگذاری، معیار پذیرش هستند.

### اصول فنی
- کدبیس هدف: SvelteKit، رابط فارسی RTL، کامپوننت‌های مستقل.
- حفظ لوگوهای واقعی بدون بازطراحی.
- تصاویر بهینه‌شده با فرمت WebP/AVIF، اندازه مناسب نمایشگر، lazy loading در زیر صفحه.
- فونت وزیر با فایل قانونی قابل انتشار و بارگذاری محلی.
- حفظ URLهای دارای ارزش سئو، تهیه نقشه مهاجرت و ریدایرکت‌های یک‌به‌یک.
- توسعه روی staging با noindex؛ سایت زنده وردپرسی `asayeshiranian.com` تا زمان تأیید نهایی تغییر نمی‌کند.
- **مخزن Public است: هرگز فایل‌های wp-config.php، رمزها، لاگ‌ها، پایگاه داده کاربران یا بک‌آپ‌های حساس را Commit نکنید.**

### وضعیت
مخزن ایجاد و چارچوب پروژه ثبت شده است. کد پروژه V6 در قالب یک بسته SvelteKit آماده شده و پیش از استقرار باید همراه دارایی‌های تصویری وارد همین مخزن و Build آن بررسی شود.
